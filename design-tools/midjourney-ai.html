Midjourney Kya Hai?
▼

Lesson 03 · Prompts
Perfect Prompt Kaise Likhein
▼

Prompt likhna ek art hai. Jitna detailed aur specific prompt, utna better result!

Prompt Formula

[Subject] + [Style] + [Lighting] + [Mood] + [Technical Details]

Example: Weak vs Strong Prompt

❌ Weak Prompt
a girl in forest
✅ Strong Prompt
a young woman standing in an ancient forest, dappled sunlight through tall oak trees, emerald green atmosphere, fantasy portrait, photorealistic, 85mm lens, soft bokeh, by Greg Rutkowski --ar 2:3 --v 6

Important Keywords Categories

🎨 Art Styles
photorealistic, oil painting, watercolor, anime, concept art, digital art, impressionist
💡 Lighting
golden hour, dramatic lighting, soft diffused light, neon lights, rim lighting, studio lighting
📷 Camera
35mm lens, wide angle, macro, aerial view, close-up portrait, shallow depth of field
🎭 Mood
ethereal, melancholic, epic, cozy, mysterious, vibrant, dark and moody

Lesson 04 · Prompts
Parameters & Commands
▼

Parameters wo special codes hain jo prompt ke end mein lagate hain — yeh image ki properties control karte hain.

Most Important Parameters

Aspect Ratio — --ar
--ar 1:1 → Square (Instagram post)
--ar 16:9 → Widescreen (wallpaper, YouTube)
--ar 9:16 → Portrait (phone, Stories)
--ar 2:3 → Portrait photo
Quality — --q
--q .25 → Fast, less detail (GPU credits bachao)
--q 1 → Default quality
--q 2 → More detail (2x GPU cost)
Stylize — --s (0-1000)
--s 0 → Very literal, exact prompt follow
--s 100 → Default balance
--s 750 → More artistic, creative liberties
--s 1000 → Maximum Midjourney style
No/Negative — --no
a landscape --no buildings, people, cars (= yeh cheezein image mein mat daalo)
💡 Version: --v 6 (latest) ya --niji 6 (anime style ke liye) use karo best results ke liye.

Lesson 05 · Advanced
Pro Techniques — Image Prompting & Remix
▼

Yeh techniques aapko beginners se alag karte hain aur professional-level output dete hain:

1. Image Prompt (Image + Text)

Apni khud ki image upload karke usse style reference dena! Pehle image Discord ya web pe upload karo, uska URL copy karo, phir:

[image_url] a person in this style, futuristic city background --iw 0.5

--iw = image weight (0.5 to 2.0) — kitna image influence karega

2. Style Reference — --sref

a serene garden --sref [style_image_url] --sw 100

3. Character Reference — --cref

portrait of a warrior --cref [character_image_url] (same character different scenes mein!)

4. Remix Mode

Variation buttons press karne ke baad aap prompt edit kar sakte ho! Settings mein "Remix Mode" ON karo.

🎯 Use Case: Ek character banao --cref se, phir usse alag alag settings (forest, city, space) mein dikhao — perfect for storytelling aur comics!

Lesson 07 · Advanced
Pro Tips, Mistakes & Resources
▼

✅ Common Mistakes Jo Beginners Karte Hain

Too vague prompts No art style mention Ignore --ar parameter First result se happy ho jana V buttons use na karna

🔥 Pro Tips

1. Seed use karo: --seed [number] same composition dobara banane ke liye

2. Multi-prompts: "red::2 apple::1" — red ko 2x importance do

3. Describe jo nahi chahiye: --no blur, ugly, distorted, watermark

4. Artist names: "in the style of Monet" ya "by Alphonse Mucha" add karo

5. Lighting is king: Har prompt mein lighting specify karo
