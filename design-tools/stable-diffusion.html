module_01

Stable Diffusion hai kya?

Stable Diffusion ek open-source image-generation model hai — matlab iska code publicly available hai, aur log ise apne computer par bhi chala sakte hain, sirf website ke through nahi.

  • Free aur customizable — koi bhi model ko modify kar sakta hai
  • Bara community ecosystem — hazaaron custom models maujood
  • Local ya cloud — apni machine par ya online run kiya ja sakta hai
module_02

Ye kaam kaise karta hai?

Iska naam hi is process ko batata hai: model ek random shor (noise) se shuru karta hai, aur qadam-ba-qadam (steps) us noise ko saaf karte hue, aapke prompt ke mutabiq ek image banata hai — bilkul jaise dhundh se dheere-dheere koi shakl nazar aane lage.

module_03

Checkpoints — alag "personalities"

Community ne Stable Diffusion ke base model ko fine-tune karke hazaaron checkpoints banaye hain — har ek ka apna style, jaise realistic photos, anime, ya fantasy art.

module_04

LoRA — chhoti add-on files

LoRA ek chhoti file hoti hai jo kisi khaas style, character, ya object ko model mein add kar deti hai — bina pura naya model banaye. Ye halki hoti hain aur jaldi load ho jaati hain.

Style LoRA

Ek specific art style ko lock karna

Character LoRA

Ek khaas character ko consistent rakhna

module_05

ControlNet — composition ka control

ControlNet aapko image ki pose, structure ya outline control karne deta hai — jaise kisi insaan ki body position ko fix rakhna, jabke baaki sab kuch AI generate kare.

module_06

Zaroori settings

STEPS Kitni baar noise saaf hoga (zyada = zyada detail, lekin slow)
CFG SCALE AI prompt ki kitni pairvi kare (zyada = strict, kam = creative)
SAMPLER Noise saaf karne ka riyaazi tareeqa (har ek ka apna look)
module_07

Positive aur Negative prompts

Positive Prompt a serene mountain lake at sunrise, misty, highly detailed, cinematic lighting
Negative Prompt: blurry, low quality, distorted

Negative prompt batata hai ke image mein kya nahi chahiye — jese blurriness ya extra fingers. Ye Stable Diffusion ka ek khaas aur bohat useful feature hai.

module_08

Zimmedari se istemal

Open-source hone ki wajah se ye control aapke haath mein zyada hota hai — isi liye zimmedari bhi zyada hai. Kisi real insaan ki deepfake image banana, ya kisi ka copyright kaam churana, in dono se bachna zaroori hai.
