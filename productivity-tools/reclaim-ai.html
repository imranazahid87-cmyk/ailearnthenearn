Reclaim AI hai kya cheez?

Normal calendar mein aap khud apne har task ke liye time nikaalte ho, aur ek naya meeting aane par sab manually adjust karna padta hai. Reclaim aapke tasks aur habits ko "smart events" ki tarah treat karta hai — jinhe wo khud priority ke hisaab se calendar mein fit karta hai aur zaroorat padne par move kar deta hai.

Auto Time-Blocking

Task diya, deadline diya — Reclaim khud decide karta hai kab us par kaam karna hai.

Habit Protection

Gym, reading, ya lunch jaisi habits ko recurring priority events ki tarah calendar mein defend karta hai.

Smart Rescheduling

Naya urgent meeting aaye toh kam-priority blocks khud reschedule ho jaate hain, important cheez chhoote nahi.

Core Features

Roz kaam aane wale features

Task add karo: "Client proposal likhna, 3 hours, Friday tak"

Reclaim aapke free slots dekh kar khud best time choose karta hai aur calendar mein block bana deta hai.

Habit banao: "Roz 30 min gym, morning preferred"

Ye recurring block calendar mein flexible priority ke saath rehta hai — kabhi shift ho sakta hai lekin miss nahi hota.

Share karo: Apna Reclaim booking link kisi ko meeting fix karne ke liye

Doosra person aapke actual free time slots dekh kar khud meeting book kar sakta hai — back-and-forth emails nahi.

Hands-On

Reclaim setup karne ka tarika

  1. Calendar connect karo

    Google Calendar (ya Outlook) link karo taaki Reclaim aapki existing meetings dekh sake.

  2. Priorities set karo

    Tasks, habits aur meetings ko priority level do — Reclaim conflict hone par isi order follow karta hai.

  3. Task/Habit add karo

    Deadline aur duration batao, baaki scheduling AI par chhod do.

  4. Calendar khud fill hone do

    Reclaim din-ba-din blocks adjust karta rahega jaise naye events aate hain.

  5. Weekly review karo

    Reclaim ka time-tracking dashboard dekho ki actually time kahan gaya.

Zaroori

Do's aur Don'ts

Kya Reclaim meetings khud cancel kar sakta hai? ▾
Nahi, ye sirf apne khud-generated task/habit blocks ko move karta hai — fixed meetings ko cancel nahi karta.
Kya priorities set karna zaroori hai? ▾
Haan, bina priority ke Reclaim ko pata nahi chalega ki conflict hone par kise pehle rakhna hai — shuru mein hi ye set kar lo.
Kya free plan mein sab features milte hain? ▾
Free plan mein basic scheduling milti hai, lekin advanced habit rules aur team features paid plans mein aate hain.
