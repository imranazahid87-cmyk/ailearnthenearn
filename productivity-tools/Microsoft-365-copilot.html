Microsoft 365 Copilot kya hai?

FOUNDATION

Microsoft 365 Copilot ek paid, work-tier AI assistant hai jo Word, Excel, PowerPoint, Outlook, aur Teams ke andar built-in hai — aur woh content padh sakta hai jispar aapki pehle se permission hai.

Yeh Microsoft Graph se connect hota hai, matlab aapke emails, chats, aur documents ke basis par personalized jawab deta hai — aur yeh public ChatGPT jaisa nahi hai: aapka data aapke tenant ke andar hi rehta hai, Microsoft usse public models train karne ke liye use nahi karta.

Copilot in Word

DRAFTING

Word mein Copilot documents draft, rewrite, aur summarize karta hai. 2026 ke naye updates ke saath ab aap:

  • Alag-alag AI models ke beech switch kar sakte ho.
  • Document ke andar hi seedha images generate kar sakte ho.
  • Purani Copilot conversations continue kar sakte ho, aur badle hue documents ke liye Catchup summaries paa sakte ho.
  • Comment-based edits automatically apply karwa sakte ho — bina manually har suggestion check kiye.

Copilot in Excel

DATA ANALYSIS

Excel mein Copilot data analyze karta hai, formulas banata hai, aur trends surface karta hai. Naye features:

  • Skills: repeatable workflows ko reusable instructions ke roop mein save kar sakte ho — common analysis ya reporting tasks ke liye.
  • Personalization: ek baar apni preferences set karo (formatting, naming, formulas, PivotTables) — Copilot har workbook mein consistently follow karega.
  • Rules sheets: spreadsheet-specific instructions jo Copilot automatically follow karta hai.

Copilot in PowerPoint

PRESENTATIONS

PowerPoint ribbon mein Copilot button dabao aur type karo, jaise "Create a 10-slide presentation on our Q1 2026 business review." Pehla draft keynote-quality nahi hoga, lekin ek minute ke andar 70% kaam ho jaata hai.

  • Brand Kit Picker se company-approved templates use kar sakte ho.
  • Reusable presentation Skills ek click mein deck par actions le sakte hain.
  • Seedha SharePoint libraries aur OneDrive folders se presentation build kar sakte ho — Copilot organization ke existing content se deck ko ground karta hai.

Copilot in Outlook

EMAIL

Outlook mein Copilot emails draft karta hai, lambi threads summarize karta hai, aur inbox prioritize karta hai. Naya update: ab aap poora draft regenerate karne ke bajaye, email ka sirf selected portion rewrite kar sakte ho.

Note: Copilot Chat ab poore inbox, calendar, aur meetings ke context mein reason kar sakta hai — matlab "what did I miss?" jaisa sawaal bhi pooch sakte ho.

Copilot in Teams

MEETINGS

Teams mein Copilot meetings aur long chats recap karta hai, action items aur decisions nikalta hai, aur "what did I miss?" jaise sawaalon ka jawab deta hai. 2026 mein yeh Teams chats, channels, calling, aur meetings — sab tak reach karta hai.

Meeting recap kaam karne ke liye live transcription enable hona zaroori hai — organizer ko "Record and transcribe → Start transcription" se shuru karna hota hai.

Agent Mode aur Deep Citations

ADVANCED

Agent Mode Word, Excel, aur PowerPoint mein generally available hai — yeh ek conversation ke through multi-step actions le sakta hai aur poore documents, workbooks, ya decks bana sakta hai jab aap review karte ho.

Deep citations aapko Copilot ke jawab verify karne dete hain — poori file ki jagah, seedha us specific hisse ka link milta hai jahan se jawab aaya.

Prompting ke pro tips

SHORTCUTS
  • Prompt mein source, goal, aur format teeno specify karo — jitna specific, utna acha result.
  • Agar Copilot irrelevant context pull kare, toh source specify karo — warna woh aapke poore account se data khींchta hai.
  • Excel mein poori sheet ke bajaye pehle relevant data filter kar lo, phir prompt do — bade datasets timeout kar sakte hain.
  • Word mein bahut chhote (200 words se kam) ya newly created documents par summary kabhi unrelated aa sakti hai — pehle OneDrive par save karo, phir try karo.
