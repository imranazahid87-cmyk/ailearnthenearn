01 · Intro

Sora hai kya cheez?

Sora, OpenAI ka text-to-video aur image-to-video model hai — Sora 2, 30 September 2025 ko release hua tha, aur tab se yeh apni cinematic realism ke liye jaana jaata hai.

Sora 2 pehle wale 6-second limit se aage badh kar 15-25 second tak ke clips synchronized audio (dialogue + sound effects) ke saath bana sakta hai. Iska ek unique feature hai "cameo" — jisme log apna consented likeness kisi generated scene mein daal sakte hain.

Cinematic quality

Film-grade output aur strong prompt-following ke liye jaana jaata hai.

Synced audio

Dialogue, sound effects aur music ek saath generate hote hain.

Cameo

Consented likeness ko scene mein daal sakte ho.

02 · Access

Ab access kaise milta hai

Consumer app band ho chuka hai, isliye ab sirf ek hi rasta bacha hai: OpenAI ka API.

  1. 01
    Developer accountOpenAI platform par API access set up karo.
  2. 02
    Model choose karoSora 2 (720p tak) ya Sora 2 Pro (true 1080p tak).
  3. 03
    Video job create karoPrompt ya image reference bhejo — yeh asynchronous flow hai.
  4. 04
    Job poll karoStatus check karte raho jab tak render complete na ho.
  5. 05
    Download karoFinal video seconds/resolution ke hisaab se bill hoti hai.
Note: ChatGPT Plus ($20/mo) ya Pro ($100-200/mo) subscription alag cheez hai — woh Sora 2 API seconds mein convert nahi hoti. Video generation ka kharcha API se alag lagta hai.

04 · Prompting

Achha prompt kaise likhein

Scene detail

Subject, setting aur lighting clearly describe karo.

Camera language

Pan, tracking shot, close-up jaise cinematic terms use karo.

Audio cue

Dialogue ya sound effect chahiye toh prompt mein likho — Sora audio bhi generate karta hai.

05 · Limits

Kya kamzoriyan hain

Sora bahut acha hai, par perfect nahi.

Long-form consistency

20-second scenes strong hain, par multi-minute storytelling abhi bhi mushkil hai.

Fine editing

Precise scene control manual production software jitna nahi hai.

Sunset risk

API 24 September 2026 ko band ho raha hai, roadmap clear nahi hai.
